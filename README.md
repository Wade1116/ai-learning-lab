# AI Learning Lab — AI 學習實驗室

一個依照 AGENTS.md 開發規則建立，可以持續擴充的個人 AI 學習筆記網站。

## 專案簡介

AI Learning Lab 是一個以大學生學習情境為主題的網站。

本專案希望探索 AI 如何協助日常學習，並透過文章記錄 AI 工具的使用方法、提示詞、操作步驟、實際成果及個人心得。

本專案的核心不只是製作網頁，而是建立一套可以重複使用的 AI 開發規則。

## AGENTS.md 開發規則

本專案使用 AGENTS.md 作為 AI 開發規範。

文件定義：

- 專案目的
- 開發技術
- 網站視覺風格
- 資料夾結構
- 檔案命名規則
- 文章內容格式
- 新增文章流程
- 修改既有內容的限制
- GitHub Pages 路徑規則
- 完成後的驗收標準

完整規則請參考：

[AGENTS.md](AGENTS.md)

## 新增文章的標準流程

未來需要新增文章時：

1. AI 先閱讀 AGENTS.md
2. 確認新文章主題
3. 檢查現有文章，避免重複
4. 參考既有文章格式
5. 在 posts/ 建立新的 HTML
6. 沿用共用 CSS
7. 更新首頁文章卡片
8. 檢查文章連結
9. 確認桌面與手機版排版
10. 回報修改內容與驗證結果

透過這套流程，未來可以持續增加文章，而不需要每次重新規劃網站結構與設計風格。

## 專案心得

這次專案讓我了解，AI 開發不只是要求 AI 產生程式碼，更重要的是先建立清楚的規則。

透過 AGENTS.md，可以讓 AI 知道網站應該使用什麼格式、如何命名檔案、如何新增文章，以及完成後需要檢查哪些項目。

在新增第四篇文章的過程中，我也體會到共用設計規則的重要性。

未來只要延續同一套規範，就能更有效率地維護與擴充網站。
