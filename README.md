# AI Learning Lab — AI 學習實驗室

這是一個依照 [`AGENTS.md`](AGENTS.md) 規則建立、可以持續擴充的個人 AI 學習筆記網站。重點不只是完成一個網頁，而是先建立清楚的專案規範，再用同一套流程持續新增文章與整理學習紀錄。

## 網站與程式碼

- **網站首頁：** https://wade1116.github.io/ai-learning-lab/
- **GitHub Repository：** https://github.com/Wade1116/ai-learning-lab
- **AI 開發規則：** [AGENTS.md](AGENTS.md)

## 專案目的

我希望把 AI 在大學生學習上的應用整理成容易閱讀的文章，包含學習目標、使用工具、提示詞、操作步驟、實際成果和個人心得。網站使用繁體中文，主要提供給想了解 AI 學習方法的大學生與初學者參考。

## 使用技術與 AI 模型

- HTML5、CSS3
- GitHub、GitHub Pages
- Markdown（AGENTS.md、README.md）
- **AI 工具與模型：ChatGPT（GPT-6）**

ChatGPT 協助規劃專案規則、產生 HTML/CSS、整理文章和設計測試流程；我負責建立 GitHub 專案、手動提交檔案、設定 GitHub Pages、檢查連結與手機版，以及提供實際測試回饋。這次沒有宣稱 AI 自動登入或直接操作 GitHub。

## AGENTS.md 的主要規則

1. 所有頁面沿用同一套配色、導覽列與共用 CSS。
2. 文章統一放在 `posts/`，檔名使用英文小寫與連字號。
3. 文章依序包含標題、日期、學習目標、AI 工具、提示詞、操作步驟、使用成果及個人心得。
4. 新增文章時要同步更新 `index.html` 的文章卡片。
5. 使用相對路徑，確保 GitHub Pages 能正常開啟。
6. 修改後要檢查連結、排版與手機版；未實際測試的項目不得宣稱通過。

## 規則重複使用測試

這次新增第四篇〈如何利用 AI 安排讀書計畫〉時，先依照 `AGENTS.md` 確認檔案命名、文章格式、共用樣式與驗收流程，再執行：

- 新增 `posts/ai-study-plan.html`
- 修改 `index.html`，加入第四張文章卡片
- 沿用 `assets/css/style.css`，不重新設計整個網站
- 由我手動提交 GitHub Commit，等待 GitHub Pages 部署，再測試文章連結與返回首頁功能

這個流程顯示，未來新增其他學習主題時，可以沿用同一套規則，不必每次重新設計網站架構。

## 驗收與已知限制

- 已檢查：首頁、四篇文章連結、返回首頁、桌面版 CSS。

- AI 產生的學習內容仍需要人工確認；網站不把未完成的實驗描述成已驗證的成果。

## 未來如何新增文章

先讓 AI 閱讀 `AGENTS.md` 與現有文章，確認主題不重複，再依照既有格式新增 `posts/新文章.html`、更新首頁卡片、檢查相對路徑及手機版，最後回報修改檔案與測試結果。

## 開發心得

這次跟之前只做單一網頁的方式不太一樣。我一開始以為把網站做出來就差不多了，但新增第四篇文章後，才比較知道先寫好規則的好處。AI 可以依照固定格式整理內容，我也比較容易知道要檢查哪些地方。過程中還是有遇到 GitHub Pages 更新延遲、卡片換行等問題，所以不能只看程式碼有沒有貼上，還是要自己打開網站測試。未來如果想繼續新增學習文章，我就可以沿用這份 `AGENTS.md`，不用每次從頭開始。
